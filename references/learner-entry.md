# 用户学习入口（V3.0 新增）

> 这是 `$ni-haixia-tcm` 的**用户首页**。
> 它**不按课程目录组织**，而是按用户"**学这个是为了做什么**"来组织。
>
> 所有内容只用于倪海厦课程学习与中医理论整理，**不作诊断、处方或个人用药建议**。
>
> **来源**：整合自 [JuneYaooo/nihaixia](https://github.com/JuneYaooo/nihaixia) 的 `learning-entry.md` + V2.1 的"7 大用户场景"。

---

## 用户学这个的核心目的

用户学习倪海厦《伤寒论》通常不是为了背课程目录，而是为了获得**六种能力**：

| 学习目的 | 用户真正想解决的问题 | 应进入的模块 |
|---|---|---|
| ① **建立辨证框架** | 一个症状怎么判断太阳、少阳、阳明、三阴？ | `colloquial-questions.md` → `symptom-index.md` → `tcm-diagnosis.md` |
| ② **掌握方证对应** | 这个方什么时候出现，和相似方怎么分？ | `formula-patterns.md` → `prescription-analysis.md`（template）|
| ③ **复盘课程内容** | 第几讲讲什么，哪些重点要记？ | `lesson-map.md` → `weekly-plan-v3.md`（template）|
| ④ **查找课程依据** | 这句话、这个方、这个板书在哪一课？ | 跳到 [JuneYaooo/nihaixia](https://github.com/JuneYaooo/nihaixia) `assets/screenshots/` |
| ⑤ **理解核心概念** | 先表后里、急下存阴、热结旁流、病名拿掉是什么意思？ | `shanghan-lun.md` + `tcm-diagnosis.md` |
| ⑥ **避免误用风险** | 哪些内容只能学习，不能自己照做？ | `honesty-boundary.md` + `formula-patterns.md` 高风险区 |
| ⑦ **复盘真实医案** | 倪师怎么治这个病的？用了什么方？ | `cases-classified.md` → `bimen-hantang.md` → `case-replay.md`（template）|

## 首屏入口（7 大场景）

### 场景 ①：我有一个症状，想按课程思路学习辨证

**适合问题**：
- "发烧恶寒无汗，课程里怎么辨？"
- "便秘但是小便清白，为什么不是阳明热实？"
- "拉清水是不是寒利？"
- "经期感冒为什么用小柴胡汤思路？"
- "手脚冷是四逆汤还是当归四逆汤？"

**回答目标**：
- 不直接给药。
- 先列分水岭：汗、寒热、口渴、小便、大便、腹诊、脉象、经期等。
- 再给可能的六经方向。
- 再列候选方证和鉴别点。
- 最后给禁忌和需要面诊的风险。

**加载顺序**：
1. `colloquial-questions.md`（先做白话翻译）
2. `symptom-index.md`
3. `tcm-diagnosis.md`
4. `formula-patterns.md`
5. 用户要证据时再跳到外部截图仓

**推荐输出格式**：

```markdown
这是课程辨证学习，不是诊断。这个主诉先看几个分水岭：

| 分水岭 | 偏向 A | 偏向 B |
| --- | --- | --- |
| 有汗/无汗 | 桂枝汤方向 | 麻黄汤方向 |
| 小便深黄/清白 | 热实 | 寒实/虚寒 |
| 腹部拒按/喜按 | 实证 | 虚证 |

按课程可能涉及 ...，但还缺 ... 才能进一步分。
```

### 场景 ②：我想查一个方子

**适合问题**：
- "麻黄汤和桂枝汤怎么分？"
- "小柴胡汤的六大主症是什么？"
- "大承气汤什么时候停？"
- "四逆散和四逆汤有什么区别？"
- "乌梅丸在厥阴病里怎么理解？"

**回答目标**：
- 方剂定位：属于哪一经、哪类病机。
- 核心方证：症状群和关键分水岭。
- 相似方鉴别：避免错用。
- 课程出处：课次与截图证据。
- 风险：尤其承气汤、四逆汤辈、附子、抵当汤、大陷胸汤。

**加载顺序**：
1. `formula-patterns.md`
2. `tcm-diagnosis.md`
3. 需要症状入口时看 `symptom-index.md`
4. 需要板书时跳到外部截图仓
5. 高风险时跳到 `honesty-boundary.md`

### 场景 ③：我想系统学六经辨证

**适合问题**：
- "六经辨证怎么入门？"
- "太阳、少阳、阳明怎么分？"
- "太阴、少阴、厥阴的核心差别是什么？"
- "从表到里的传变路线是什么？"

**回答目标**：
- 先给六经总表。
- 再给每一经的主症、病机、代表方、禁忌。
- 最后给"从症状进入"的练习题。

**加载顺序**：
1. `tcm-diagnosis.md`
2. `formula-patterns.md`
3. `lesson-map.md`
4. `weekly-plan-v3.md`（生成 12 周学习计划）

### 场景 ④：我想按课程复习

**适合问题**：
- "从第 07 讲开始复习。"
- "第 13 讲讲了什么？"
- "帮我把 15 课做一个复习计划。"
- "每节课给我重点方证和截图。"

**回答目标**：
- 每课输出：主题、核心方证、关键分水岭、风险点、截图关键词、复习题。
- 不把逐课复习变成流水账，要把课次内容转成可记忆的卡片。

**加载顺序**：
1. `lesson-map.md`
2. 按课次跳到外部截图仓
3. 涉及方剂时打开 `formula-patterns.md`
4. 套用 `weekly-plan-v3.md` 模板

**推荐复习卡格式**：

```markdown
### 伤寒论07

- 主题：蓄血、结胸、脏结、阴实
- 必记分水岭：少腹硬满 + 小便自利 -> 蓄血方向
- 重点方证：抵当汤/丸、大陷胸汤/丸
- 高风险：破血、攻逐、癌症/阴实只能学习
- 截图索引：[JuneYaooo/nihaixia 伤寒论07](https://github.com/JuneYaooo/nihaixia/tree/main/assets/screenshots/shanghanlun)
- 自测题：如何区分蓄血和阳明燥屎？
```

### 场景 ⑤：我想理解一个课程概念

**适合问题**：
- "先表后里是什么意思？"
- "为什么有表证时不可攻下？"
- "热结旁流为什么看起来像腹泻？"
- "急下存阴是什么意思？"
- "病名拿掉、中虚为明是什么意思？"

**回答目标**：
- 先用一句话解释概念。
- 再说明它解决的辨证问题。
- 给出常见误用风险（有表证不可攻下、少阴不可发汗、承气汤中病即止）。
- 提供对应课次或截图证据。

**加载顺序**：
1. `shanghan-lun.md`
2. `lesson-map.md`
3. 跳到外部截图仓

**概念示例**：

> **先表后里**：课程里指表证还在时，先处理表证；若表证未解就攻里/攻下，容易使邪气内陷，形成心下痞、结胸、下利等变证。因此用户问"能不能先攻下"时，要特别说明"有表证不可攻下"。

### 场景 ⑥：我想查板书截图或课程依据

**适合问题**：
- "小柴胡汤加减的板书在哪？"
- "热结旁流有没有图？"
- "乌梅丸的方子截图给我。"
- "这个观点是哪一课讲的？"

**回答目标**：
- 返回 3 到 8 条最相关证据。
- 优先返回同时命中关键方名、病机或课次的条目，不要只因为"加减""方剂"等泛词命中就返回。
- 每条包含：课次、时间点、说明、外部截图路径。
- 如用户明确说"显示"，可打开对应图片。

**加载顺序**：
1. 跳到 [JuneYaooo/nihaixia](https://github.com/JuneYaooo/nihaixia) `assets/screenshots/`
2. 必要时回查 `lesson-map.md` 或 `formula-patterns.md`
3. 多关键词截图检索优先运行：`python scripts/search_screenshots.py 小柴胡汤 加减`（需下载 JuneYaooo/nihaixia 仓）

**输出格式**：

```markdown
- 伤寒论05 82:42：小柴胡汤加减法板书
  截图路径：JuneYaooo/nihaixia/assets/screenshots/shanghanlun/0182.webp
```

### 场景 ⑦：我想做安全边界判断

**适合问题**：
- "哪些方不能自己乱用？"
- "四逆汤为什么危险？"
- "急下存阴能不能照课程做？"
- "癌症阴实这部分怎么学习比较安全？"

**回答目标**：
- 明确区分"课程理论"和"真实临床"。
- 列高风险方药与高风险场景。
- **不提供可执行剂量和自用步骤**。
- 提醒执业医师面诊或急诊。

**高风险关键词**：
- 附子、生附子、炮附子、生硫磺（**倪师区分三种，功能完全不同**）
- 四逆汤、通脉四逆汤、白通汤、白通加猪胆汁汤、真武汤
- 大承气汤、小承气汤、调胃承气汤、急下存阴、热结旁流
- 抵当汤、大陷胸汤、桃核承气汤
- 癌症、肿瘤、阴实、附骨脉、主动脉剥离
- 孕产妇、儿童、老人、胸痛、急腹痛、神志异常、脱水、休克

**加载顺序**：
1. `honesty-boundary.md`（必读）
2. `formula-patterns.md` 高风险区
3. `bimen-hantang.md`（闭门课 7 大重病）
4. `safety-boundary` 标注

**标准安全回答**：

> 这部分只能作为倪海厦课程理论学习。它涉及峻烈攻下、破血、附子回阳或危重症判断，不能作为个人用药建议。真实病情必须由执业中医师面诊辨证；若有胸痛、急腹痛、意识改变、脱水或休克样表现，应立即急诊。

## 推荐学习路径（4 条）

### 路径 1：入门路径（先会分辨，不急着记方）

1. 读 `tcm-diagnosis.md` 的总览表。
2. 读 `symptom-index.md` 的快速分水岭。
3. 读 `colloquial-questions.md` 18 个白话场景。
4. 用 5 个问题练习：发热、便秘、下利、腹痛、手足冷。
5. 再进入 `formula-patterns.md` 看代表方。

**预计时间**：2-4 周。

### 路径 2：方证路径（适合已有中医基础的人）

1. 从桂枝汤/麻黄汤、小柴胡汤、白虎汤/承气汤、四逆汤/当归四逆汤四组开始。
2. 每组只记三个东西：主症、鉴别点、禁忌。
3. 用外部截图仓（JuneYaooo/nihaixia）找板书证据加强记忆。
4. 套用 `prescription-analysis.md` 模板做方剂解析。

**预计时间**：4-6 周。

### 路径 3：逐课路径（适合跟视频复习）

1. 用 `lesson-map.md` 看每讲主题。
2. 每讲提炼 3 张卡片：病机卡、方证卡、禁忌卡。
3. 每讲保留 3 到 5 张关键截图作为复习锚点（来自 JuneYaooo/nihaixia）。
4. 套用 `weekly-plan-v3.md` 模板做 15 周学习计划。

**预计时间**：15-30 周。

### 路径 4：研究路径（适合做二次蒸馏）

1. 先按主题而不是课次聚合：太阳病、少阳病、阳明病、三阴病、误治变证、闭门课 7 大重病。
2. 每个主题绑定：核心概念、关键方证、症状入口、截图证据。
3. 最后再回到课程课次，保证出处可追溯。
4. 参考 `bimen-hantang.md`（闭门课 7 大重病）+ `cases-classified.md`（245 分类医案）。

**预计时间**：3-6 个月。

### 路径 5：医案复盘路径（新加）

1. 选一个病种（如癌症、糖尿病、肾衰竭）。
2. 打开 `cases-classified.md` 对应章节，挑 3-5 个医案。
3. 用 `case-replay.md` 模板：遮住六经/方剂 → 自己辨证 → 对比倪师。
4. 进一步查 `bimen-hantang.md` 看闭门课相关专题。
5. 最后用 `formula-patterns.md` + `drug-properties.md` 复盘方义。

**预计时间**：每个病种 1-2 周。

## 判断回答是否适合用户

一个好的 `$ni-haixia-tcm` 回答应满足：

- 用户能知道下一步该看什么，而不是只看到大段课程摘要。
- 用户能看懂分水岭，比如有汗/无汗、小便深黄/清白、腹部拒按/喜按。
- 用户能区分相似方，而不是只知道方名。
- 用户能追溯到课次和截图。
- **用户不会误以为可以自行照方用药。**
