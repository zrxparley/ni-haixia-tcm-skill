# 黄帝内经核心摘要（倪海厦体系）

倪师原话："内经是中医的圣经，针灸学会再看内经会恍然大悟。"

---

## 总纲

《黄帝内经》分《素问》与《灵枢》两部分，倪师强调重点读《素问》，针灸原理看《灵枢》。

---

## 核心篇章（倪师指定必读）

### 上古天真论（养生根本）
**核心思想**：法于阴阳，和于术数，食饮有节，起居有常，不妄作劳。
**倪师讲解**：
- 女七男八的生长周期：女子七岁肾气盛，二七天癸至；男子八岁肾气实，二八肾气盛。
- 今时之人：以酒为浆，以妄为常，醉以入房——这是现代人早衰的根本原因。
- 真人/至人/圣人/贤人：四种养生境界。

### 阴阳应象大论（阴阳辨证总纲）
**核心条文**："阴阳者，天地之道也，万物之纲纪，变化之父母，生杀之本始，神明之府也。"
**倪师讲解**：
- 阴阳是辨证的根本，所有病证都可以用阴阳解释。
- 阳胜则热，阴胜则寒；重寒则热，重热则寒。
- 治病必求于本——本就是阴阳。

### 藏象论（五脏六腑功能）
**五脏**：心藏神，肺藏气，肝藏血，脾藏肉，肾藏志。
**倪师讲解**：
- 心为君主之官，神明出焉——治心病先治肾（水火既济）。
- 肺为相傅之官，治节出焉——肺主皮毛，皮肤病从肺治。
- 肝为将军之官，谋虑出焉——肝主疏泄，情绪病从肝治。
- 脾为谏议之官，知周出焉——脾主运化，脾胃为后天之本。
- 肾为作强之官，伎巧出焉——肾主藏精，为先天之本。

### 六节藏象论（天地与人体）
**核心**：天以六六为节，地以九九制会。
**倪师讲解**：人与天地相应，故五脏应五时（肝应春、心应夏、脾应长夏、肺应秋、肾应冬）。

### 移精变气论（祝由十三科）
**核心**：古之治病，惟其移精变气，可祝由而已。
**倪师讲解**：
- 祝由科是中医十三科之一，用符咒移精变气。
- 现代心理学、安慰剂效应，都是祝由的现代版。
- 倪师本人在临床中也会用"祝由"之法（语言引导、心理暗示）。

## 阴阳辨证总纲（倪师提炼）

### 阴阳症状表现
| | 阳证 | 阴证 |
|--|--------|--------|
| 寒热 | 发热、恶热 | 畏寒、四逆 |
| 口渴 | 渴喜冷饮 | 不渴或喜热饮 |
| 大小便 | 便秘、小便黄赤 | 下利清谷、小便清长 |
| 舌苔 | 舌红苔黄 | 舌淡苔白 |
| 脉象 | 浮大数实 | 沉迟细弱 |
| 精神 | 烦躁、失眠 | 但欲寐、萎靡 |

### 调整阴阳原则
- 阳胜则阴病 → 泻阳救阴（如白虎汤、承气汤）
- 阴胜则阳病 → 温阳祛阴（如四逆汤、理中汤）
- 阴虚 → 滋阴（如六味地黄丸、黄连阿胶汤）
- 阳虚 → 扶阳（如四逆汤、真武汤）

## 五行与五脏关系（倪师图解）

```
木 → 火 → 土 → 金 → 水（相生）
木克土，土克水，水克火，火克金，金克木（相克）

肝（木） → 心（火） → 脾（土） → 肺（金） → 肾（水）
```

**倪师临床应用**：
- 肝病传脾 → 治肝先实脾（见肝之病，知肝传脾，当先实脾）
- 心病传肺 → 治心先清肺
- 这是"治未病"的核心思想

## 倪师内经学习法

### 第一步：背熟条文
上古天真论、阴阳应象大论、藏象论——这三篇必须能背诵。

### 第二步：画图理解
画五脏关系图、五行生克图，把抽象理论变成可视化结构。

### 第三步：临床验证
每读一条经文，找倪师医案中对应的临床应用，验证理论。

### 第四步：现代语言重述
用现代人能理解的语言重新讲一遍（倪师本人就是这样做的）。
