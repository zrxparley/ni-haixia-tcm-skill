## 二、关键方详解

### 方 1：清肺排毒汤（21 味大复方）

**来源**：抗疫通用方，由五个经方合并而成

**组成**：
- 麻杏石甘汤（麻黄+杏仁+石膏+甘草）
- 射干麻黄汤（射干+麻黄+生姜+细辛+紫菀+款冬花+五味子+半夏+大枣）
- 小柴胡汤（柴胡+黄芩+半夏+人参+甘草+生姜+大枣）
- 五苓散（茯苓+猪苓+泽泻+白术+桂枝）
- 橘枳姜汤（橘皮+枳实+生姜）

**安全性**：⚠️ **不可自用**，必须在执业中医师指导下使用

### 方 2：治胃病万能公式（五个泻心汤辨证）

**核心**：半夏泻心汤 + 柴胡郁金 + 茯苓白术

**五个泻心汤辨证**（故乡的云总结）：
1. **半夏泻心汤** → 心下痞满、恶心呕吐
2. **生姜泻心汤** → 噫气、嗳气
3. **甘草泻心汤** → 重度心下痞、腹泻
4. **大黄黄连泻心汤** → 热痞（制法：热水泡取气，不可煮）
5. **附子泻心汤** → 痞证兼阳虚

### 方 3：肺结节

**组成**：百合 35g + 川贝 + 浙贝 + 茯苓 + 桔梗

**状态**：⚠️ 维护者标记"待参透"，需进一步研究

### 方 4：久坐腰痛（大剂量经方）

**组成**：
- 白术 150g
- 薏仁 150g
- 芡实 100g

**来源**：石室秘录

**清朝度量衡换算**：
- 1 斤 = 596g
- 1 两 = 37.3g

**安全性**：⚠️ **大剂量**，需医师面诊

### 方 5：刀片嗓子

**组成**：玄麦甘桔颗粒（中成药）

**适用**：阴虚火旺

**安全性**：✅ 中成药相对安全

### 方 6：荨麻疹

**两种方案**：
- 桂枝麻黄各半汤
- 麻黄加术汤

**含颜北辰医案**（倪师传人）

**安全性**：⚠️ 麻黄需辨证

### 方 8：斑秃外涂

**组成**：香油 + 蒜泥

**安全性**：✅ 外用相对安全

### 方 10：甲沟炎（中西结合）

**组成**：
- 阿莫西林粉（西药）
- 艾灸悬灸 1 小时（中医外治）

**思路**：抗生素杀菌 + 艾灸促进血液循环

**安全性**：✅ 中西结合，但需医师诊断是否需要抗生素

### 方 11：灰指甲（外用）

**组成**：
- 商陆（有毒）
- 大蒜
- 白醋 15°
- 浸泡

**安全性**：⚠️ **商陆有毒，仅可外用，不可内服**

### 方 12：外用美容祛斑

**组成**：亚麻籽 + 当归 + 西洋参 煮敷脸

**来源**：张孟超（倪师真传弟子）分享

**安全性**：✅ 外用

### 方 13：紫云膏（外伤烫伤）

**组成**：紫草 + 当归 + 麻油 + 蜂蜡 + ...

**来源**：李宗恩养正育儿方

**附加知识**：**扭伤不用冰敷**（倪师辟谣），扭伤应该热敷

**安全性**：✅ 外用

### 方 14：三黄膏（蚊虫叮咬/青春痘）

**组成**：9 味药油膏
- 黄连 + 黄芩 + 黄柏
- + ...

**来源**：李宗恩方

**安全性**：✅ 外用

### 方 15：益气聪明汤

**组成**：
- 黄芪 + 人参（补气）
- 葛根 + 蔓荆（升清）
- 白芍（平肝）
- 黄柏（清热）
- 升麻（升举）
- 炙甘草（调和）

**来源**：东桓试效方

**适应症**：让孩子聪明（实际是治疗眼耳聪明）

**安全性**：⚠️ 需辨证

### 方 16：产后调养（完整流程）

**四个阶段**：
1. **产前**：调理母体
2. **住院**：生化汤（产后第一方）
3. **回家**：小柴胡汤+理中汤
4. **脱发**：八珍+胎盘粉

**安全性**：⚠️ 需专业医师指导

### 方 17：王不留行散（剖腹产金疮药）

**组成**：
- 王不留行
- 蒴藋细叶
- 桑白皮
- 甘草
- 川椒
- 黄芩
- 干姜
- 芍药
- 厚朴

**来源**：桂林古本伤寒方

**制备方法**：详见原文

**不良反应应对**：上吐下泻 → 附子理中丸

## 三、使用原则

1. **优先级**：倪师原方 > 紫极先生补全 > 故乡的云总结 > 民间偏方
2. **大剂量方**（如方 4 久坐腰痛）**必须**医师面诊
3. **有毒药物**（如商陆、蓖麻子、生附子、生硫磺）**必须**专业指导
4. **中成药**（如玄麦甘桔、逍遥丸）相对安全，但仍需看说明
5. **外用方**相对安全，但仍需先小面积测试过敏
