# 神农本草经核心药性（倪海厦体系）

倪师强调：药性要从"药象"理解，不要死记。"知道药走到哪条经，才能知道怎么用。"

## 倪师用药心法

### 一、药象思维
- 桂枝：像血管末梢 → 走四肢末梢，温通经脉
- 麻黄：像麻黄碱分子结构 → 开毛孔，发汗
- 石膏：白色，质重 → 清气分实热，重镇降逆
- 附子：黑色，性热 → 入肾经，回阳救逆

### 二、归经口诀
```
手太阴肺：白芷、细辛、生姜、麻黄
手阳明大肠：白芷、石膏、大黄
足阳明胃：石膏、大黄、干姜
足太阴脾：白术、茯苓、干姜、人参
手少阴心：黄连、阿胶、附子
手太阳小肠：滑石、木通
足太阳膀胱：麻黄、桂枝、茯苓
足少阴肾：附子、肉桂、熟地、山药
手厥阴心包：黄连、牛黄
手少阳三焦：柴胡、黄芩
足少阳胆：柴胡、黄芩、龙胆草
足厥阴肝：当归、白芍、川芎、吴茱萸
```

### 三、配伍禁忌（倪师强调）

**十八反**：
- 甘草反：甘遂、大戟、海藻、芫花
- 乌头反：贝母、瓜蒌、半夏、白蔹、白及
- 藜芦反：人参、沙参、丹参、玄参、苦参、细辛、芍药

**十九畏**（倪师认为部分可酌情使用）：
- 硫磺畏朴硝，水银畏砒霜
- 狼毒畏密陀僧，巴豆畏牵牛
- 丁香畏郁金，牙硝畏三棱
- 川乌/草乌畏犀角，人参畏五灵脂
- 官桂畏赤石脂

### 四、倪师常用配伍

| 配伍 | 功效 | 代表方 |
|------|------|--------|
| 桂枝 + 芍药 | 调和营卫 | 桂枝汤 |
| 麻黄 + 桂枝 | 发汗解表 | 麻黄汤 |
| 石膏 + 知母 | 清气分热 | 白虎汤 |
| 大黄 + 芒硝 | 峻下热结 | 大承气汤 |
| 柴胡 + 黄芩 | 和解少阳 | 小柴胡汤 |
| 附子 + 干姜 | 回阳救逆 | 四逆汤 |
| 当归 + 芍药 | 养血和血 | 当归芍药散 |
| 黄连 + 黄芩 | 清热燥湿 | 泻心汤 |

## 倪师用药剂量心法

> "经方剂量是倪师反复强调的重点，现代用药量太小是疗效不好的主要原因。"

### 经方剂量换算（倪师标准）
- 一两 ≈ 15.625g（汉代度量衡）
- 一升 ≈ 200ml
- 一方寸匕 ≈ 7-8g
- 一钱匕 ≈ 2-3g

### 倪师实际常用量
| 药名 | 经方原量 | 倪师常用量 |
|------|----------|------------|
| 桂枝 | 三两 | 15-45g |
| 麻黄 | 三两 | 9-18g（先煎去沫）|
| 附子 | 一枚 | 炮附子15-30g，生附子6-9g |
| 石膏 | 一斤 | 60-250g |
| 大黄 | 四两 | 12-60g |
| 细辛 | 二两 | 9-30g |
| 柴胡 | 半斤 | 24-125g |
| 甘草 | 二两 | 6-30g |

> 倪师原话："量不够，如水投石；量够，一剂知，二剂已。"
