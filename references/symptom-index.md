# 症状入口索引

> 医疗边界：本文件仅作课程学习、资料检索和中医理论整理；涉及真实症状、诊断、处方、剂量、针灸操作、急症、孕产儿童、肿瘤或附子等高风险内容时，不能作为个人医疗建议或自行操作依据，应咨询合格医疗专业人员。
> 
> 从用户主诉反推课程中的辨证分水岭。使用时先收集缺失信息，再进入六经和方证模块。仅供学习。

## 发热、恶寒、汗出

必须问：

- 有汗还是无汗。
- 恶风还是恶寒。
- 身痛、项背强、喘、烦躁有无。
- 口渴、小便颜色、大便情况。
- 咽喉是否干燥，尺脉是否迟微。

课程辨法：

- 有汗、恶风、脉缓：太阳中风，桂枝汤方向。
- 无汗、体痛、脉紧：太阳伤寒，麻黄汤方向。
- 项背强几几、无汗、恶风：葛根汤方向。
- 无汗烦躁、表寒里热：大青龙汤方向。
- 但热不寒、大渴：阳明经热，白虎汤方向。

禁忌：

- 咽干、淋家、疮家、尺脉迟微，课程均列为发汗禁忌。
- 少阴病脉微细但欲寐不可按太阳病发汗。

## 往来寒热、胸胁苦满、恶心

必须问：

- 寒热是否"来回发作"，还是持续高热。
- 是否胸胁苦满、口苦、恶心。
- 女性是否月经期。
- 是否已有误下、误汗。

课程辨法：

- 少阳枢机不利：小柴胡汤方向。
- 一半太阳一半少阳：柴胡桂枝汤方向。
- 经期外感：热入血室，课程强调直接和解，不发汗。
- 少阳兼阳明实热：柴胡加芒硝汤方向。

## 口渴与饮水

必须问：

- 渴欲饮水还是口渴不欲饮。
- 小便深黄/清白/不利。
- 有无高热、大汗、大便结。

课程辨法：

- 阳明大热大渴：白虎汤或白虎加人参汤方向。
- 蓄血常见口渴不欲饮、小便自利。
- 少阴自利而渴，小便色白，偏下焦寒水不能气化。
- 水逆：喝水反吐，五苓散方向。

## 便秘

必须问：

- 大便几日不通，是否放屁。
- 小便颜色（深黄=热实，清白=寒实/虚）。
- 腹部是否拒按、有硬块。
- 是否潮热、谵语。

课程辨法：

- 阳明腑实、潮热、放屁、谵语：承气汤辈方向。
- 脾约（胃强脾弱、小便数、大便硬）：麻子仁丸方向。
- 寒实积滞、不发热、小便清白：四逆汤辈/温下方向，非承气汤。
- 蓄血兼便秘、少腹急结、小便自利：桃核承气汤方向。

禁忌：

- 承气汤中病即止，不可过剂伤正。
- 寒实便秘误用承气汤会导致下利清谷、四肢厥逆。

## 下利

必须问：

- 热利（臭秽、灼肛、口渴）还是寒利（清谷、不臭、小便清白）。
- 是否有表证未解。
- 腹痛喜按还是拒按。

课程辨法：

- 热利、脉促、喘而汗出：葛根芩连汤方向。
- 寒利、心下痞硬、表未解：桂枝人参汤方向。
- 热结旁流（大便清水、内有燥屎）：大承气汤急下存阴。
- 少阴下利清谷、手足厥冷：四逆汤辈方向。

## 腹胀腹痛

必须问：

- 喜按（虚）还是拒按（实）。
- 时痛时止（气滞/虚寒）还是持续痛（实）。
- 是否便秘或下利。

课程辨法：

- 腹胀满、按之痛（实）：承气汤方向。
- 腹满而吐、食不下、时腹自痛（太阴）：理中汤/四逆辈方向。
- 发汗后腹胀、纳差：厚姜半甘参汤方向。
- 心下痞（按之软、不痛）：泻心汤类方向。

## 失眠、烦躁

必须问：

- 是"虚烦不得眠"（汗吐下后）还是"心中烦、不得卧"（少阴热化）。
- 昼日烦躁还是夜间烦躁。
- 是否有表证未解。

课程辨法：

- 汗吐下后虚烦不得眠：栀子豉汤方向。
- 发汗后昼日烦躁、夜而安静、脉沉微：干姜附子汤方向。
- 少阴热化、心中烦、不得卧：黄连阿胶汤方向。
- 阴虚火旺、心悸失眠：黄连阿胶汤/朱砂安神方向。

## 手足冷、厥逆

必须问：

- 冷到手指/足趾，还是冷至肘/膝。
- 是否下利清谷、小便清长。
- 脉象（脉沉微=阳虚，脉弦/脉滑=阳郁）。

课程辨法：

- 手足厥冷、脉细欲绝、内有久寒：当归四逆汤/当归四逆加吴茱萸生姜汤方向。
- 少阴四逆、下利清谷、脉沉微：四逆汤辈方向。
- 阳郁厥逆（手足冷但脉沉弦/滑、胸胁苦满）：四逆散方向。
- 厥阴蛔厥、时厥时止：乌梅丸方向。

禁忌：

- 四逆汤辈含附子，不可自行照方用药，须执业中医师面诊。
- 阳郁厥逆（四逆散证）误用附子会加重病情。

## 使用方式

1. 用户描述症状后，先查本文件"快速分水岭"表，定位第一分水岭。
2. 按症状类别读取对应章节的"必须问"清单，补全信息。
3. 用"课程辨法"给出学习方向，不直接开处方。
4. 涉及高风险方剂（承气汤、四逆汤、抵当汤、附子剂）时，输出安全边界声明。
5. 需要课程板书证据时，检索 `screenshot-evidence.md` 对应课次条目。
