### 三、五味之用

| 五味 | 功能 |
|---|---|
| 酸 | 能涩、能收 |
| 苦 | 能泻、能燥、能坚 |
| 甘 | 能补、能和、能缓 |

| 淡 | 能利窍、能渗泄 |

### 四、阴阳之义

- **寒热温凉是气（阳）**
- **酸苦甘辛咸是味（阴）**
- 气厚为阳中之阳，薄为阳中之阴
- 味厚为阴中之阴，薄为阴中之阳
- 辛甘发散为阳，酸苦涌泄为阴

### 五、五脏补泻

| 脏 | 苦 | 欲 | 补 | 泻 |
|---|---|---|---|---|
| 肝 | 急 | 散 | 辛 | 酸 |
| 心 | 缓 | 软 | 咸 | 甘 |
| 脾 | 湿 | 缓 | 甘 | 苦 |
| 肺 | 气上逆 | 收 | 酸 | 辛 |
| 肾 | 燥 | 坚 | 苦 | 咸 |

**倪师临床详解**：
- 肝苦急（肝气太急）→ 食甘缓之（用甘味药让它缓和）
- 心苦缓（心气太缓）→ 食酸收之
- 脾苦湿（脾被湿困）→ 食苦燥之（苦味药燥湿）
- 肺苦气上逆（咳嗽气喘）→ 食苦泻之
- 肾苦燥（肾阴不足）→ 食辛润之

### 六、六淫主治

| 淫 | 治 | 佐 |
|---|---|---|
| 风 | 辛凉 | 苦甘 |
| 热 | 咸寒 | 甘苦 |
| 湿 | 苦热 | 酸淡 |
| 火 | 咸冷 | 苦辛 |
| 燥 | 苦温 | 甘辛 |
| 寒 | 甘热 | 苦辛 |

### 七、五行相生

- **虚则补其母**
- **实则泻其子**
- 例：肾为肝母，心为肝子 → 入肝者并入肾与心

### 八、五病所禁

- 筋病勿多食酸
- 骨病勿多食苦
- 肉病勿多食甘
- 气病勿多食辛
- 血病勿多食咸

### 九、炮制总义

- **酒制升提**（往上走）
- **姜制温散**（散寒）
- **入盐走肾而软坚**
- **用醋注肝而收敛**
- **蜜制甘缓益元**

## 第二部分：倪师药性总义·视频讲义深度精萃

> 以下内容蒸馏自倪海厦神农本草经视频讲义。

### 一、五味之用·倪师临床详解

#### 酸味——能收、能涩

**收敛场景**：
- 下利不止
- 流汗不止
- 舌头吐出收不回
- 大小便失禁
- 眼睛闭不起来（→ 用酸味药，开阖功能）
- 考试紧张就下利（→ 酸味药如乌梅）

**涩剂代表**：乌梅最酸（梅子还泡醋制过），久利用涩。

**禁忌**：
- 筋病（抽筋）勿多食酸
- 酸主收敛 → 筋会缩得更严重

#### 苦味——能泻、能燥、能坚

**泻**：食物中毒 → 苦味药攻下排出

**燥**：湿重 → 苦味药燥湿（舌苔厚、口水多）

**坚**：不够坚硬 → 苦味药壮阳（苦味入心，心主火）

**区分固精与壮阳**：
- 壮阳让它硬 → 苦味药
- 固精不让它漏 → 不同处方

#### 甘味——能补、能和、能缓

**补**：补气血、补阴阳

**和**：调和诸药（如甘草）

**缓**：缓急止痛（如芍药甘草汤，缓急解痛）

#### 辛味——能散、能润、能横行

**散**：发散风寒（麻黄、桂枝）

**润**：辛润（如菟丝子、麦冬）

**横行**：走窜（如川芎上行头目、下行血海）

#### 咸味——能下、能软坚

**下**：通便（如芒硝）

**软坚**：软化硬块（如牡蛎、瓦楞子，治乳癌/淋巴癌硬块）

#### 淡味——能利窍、能渗泄

**利窍**：通利小便（如茯苓、泽泻）

**渗泄**：渗湿利水（如薏苡仁）

### 二、阴阳之义·倪师临床详解

#### 寒热温凉是气（阳）

- **寒**：清热（如黄连、黄芩、黄柏）
- **热**：温阳（如附子、肉桂、干姜）
- **温**：温和（如生姜、桂枝）
- **凉**：清润（如薄荷、菊花）

#### 酸苦甘辛咸是味（阴）

- 味厚为阴中之阴（如大黄、芒硝）
- 味薄为阴中之阳（如生姜、葱白）

#### 辛甘发散为阳，酸苦涌泄为阴

- 发散类（麻黄、桂枝）→ 阳
- 收敛/攻下类（乌梅、大黄）→ 阴

---

### 三、升降浮沉·倪师临床详解

| 性 | 方向 | 例子 |
|---|---|---|
| 升 | 往上 | 升麻、柴胡、葛根 |
| 浮 | 往外 | 麻黄、桂枝、薄荷 |
| 降 | 往下 | 苏子、莱菔子 |
| 沉 | 往里 | 牡蛎、龙骨、磁石 |

**倪师临床要点**：
- 头面病 → 用升浮药（引药上行）
- 下焦病 → 用沉降药（引药下行）
- 上盛下虚 → 升清降浊
- 病在表 → 用浮药（发散）
- 病在里 → 用沉药（攻下）

#### 质轻质重

- 质轻 → 升浮（如薄荷、蝉蜕）
- 质重 → 沉降（如赭石、磁石）

#### 倪师药性心法："以意来得"

> "你看到药的颜色、形状、质地、味道，就能判断它的归经和功能"

**示例**：
- 何首乌黑 → 入肾补精
- 红花红 → 入心活血
- 黄芩黄 → 入脾胃清湿热
- 紫根紫 → 入血分活血化瘀（乳癌开过刀后用）
- 防己（粉防己）色白入肺、入三焦

### 四、五脏补泻·倪师临床详解

#### 肝

- 补肝：辛味（散肝用辛；如当归、川芎）
- 泻肝：酸味（收敛疏泄太过）
- 临床：肝火旺 → 用酸（白芍）收敛

#### 心

- 补心：咸味（软化坚结；如芒硝、牡蛎）
- 泻心：甘味（缓心火）
- 临床：心火旺 → 用甘（甘草、小麦）

#### 脾

- 补脾：甘味（甘温补脾；如党参、白术）
- 泻脾：苦味（苦燥湿；如黄连、黄芩）
- 临床：脾湿 → 用苦（黄连燥湿）

#### 肺

- 补肺：酸味（收敛肺气；如五味子）
- 泻肺：辛味（发散肺气；如麻黄、杏仁）
- 临床：肺虚咳嗽 → 用酸（五味子、乌梅）

#### 肾

- 补肾：苦味（坚肾；如知母、黄柏）
- 泻肾：咸味（软坚；如芒硝、牡蛎）
- 临床：肾虚 → 用苦（知母、黄柏坚阴）

### 六、倪海厦独创药性心法

#### 1. 热极生寒·倪海厦独创

> **核心**：当人体热到极点时，反而出现寒象。

**机制**：
- 心阳极衰 → 阴寒内盛 → 出现四肢冰冷、脉微欲绝
- 实际是"真寒假热"
- 治疗**不是**清热，而是**回阳**（生附子、四逆汤）

**临床应用**：
- 红斑性狼疮：手脚冰冷、脉微 → 用生附子+大剂石膏（详见 `bimen-hantang.md`）
- 倪师："石膏大剂 60g 下去，把胸腔奶水逼出来"

**判断要点**：
- 舌苔黄干（似热） + 脉微欲绝（实寒） → 真寒假热
- 不可单用清热

#### 2. 以通为补·倪海厦用药哲学

> **核心**：当人体有积滞时，通就是补。

**机制**：
- 大便不通 → 浊气上逆 → 头昏、烦躁、口苦
- 通了 → 浊气下泄 → 头清目明
- 倪师："补药的定义并不是说一定要去吃大补的东西，把大便清出来就是补药"

**临床应用**：
- 大承气汤急下存阴
- 桔梗排脓
- 大黄、芒硝攻坚

**金句**：
- "瘀不去，新血不生"
- "当你遇到贫血的时候，不是一味开补血药"

#### 3. 五味临床详解（核心心法）

| 五味 | 主治 | 代表药 | 禁忌 |
|---|---|---|---|
| 酸 | 收敛固涩 | 乌梅、五味子、山茱萸 | 筋病、外感初期 |
| 苦 | 清热燥湿、坚阴 | 黄连、黄芩、黄柏、大黄 | 脾虚、胃寒 |
| 甘 | 补益调和 | 党参、甘草、大枣 | 湿盛、痰多 |
| 辛 | 发散行气 | 麻黄、桂枝、川芎 | 气虚、阴虚 |
| 咸 | 软坚通下 | 芒硝、牡蛎、瓦楞子 | 脾虚 |

### 七、炮制临床要点

| 炮制 | 目的 | 代表药 |
|---|---|---|
| 酒制 | 升提（往上走） | 当归（酒制活血更强） |
| 姜制 | 温散（散寒） | 竹茹（姜制止呕） |
| 盐制 | 走肾软坚 | 杜仲（盐制入肾） |
| 醋制 | 注肝收敛 | 延胡索（醋制止痛） |
| 蜜制 | 甘缓益元 | 甘草（蜜制补气） |
| 煅 | 改变药性 | 石膏（生用清热，煅用收湿） |
| 炒 | 减低毒性 | 蓖麻子（炒熟外敷） |
| 蒸 | 改变归经 | 何首乌（蒸后入肾补精） |

**倪师炮制心法**：
- **石膏必须用生石膏**，煅石膏无效（清热作用消失）
- **大黄黄连泻心汤**用热水泡取气，不可煮
- **附子必须炮制**（生附子有毒），但炮附子和生附子功能**完全不同**（详见下文）

### 八、附子三品功能精确区分（**倪师核心临床创新**）

> ⚠️ **倪师最核心的临床创新之一**。本节内容是倪海厦区分三种"附子类"药物的关键心法，**也是最容易混淆和误用**的部分。

| 药物 | 靶器官 | 功能 | 比喻 | 适应症 |
|---|---|---|---|---|
| **生附子** | 心脏 | 强心阳、起阳 | 阳气从 50 回到 100 | 手脚冰冷（真冷）、心阳不足、四逆汤证 |
| **炮附子** | 肾脏/表 | 固肾阳、敛表阳、止汗 | 阳气从 100 流失到 50，炮附子保住 50 | 表阳虚盗汗、亡阳初期、保守现有阳气 |
| **生硫磺** | 命门 | 强命门火、气化全身水湿 | 性轻飘如麻黄，可升达头部 | 命门火衰、水肿难消、脑瘤（阳需达脑部时） |

#### 临床鉴别决策树

```
症状：手脚冰冷
├── 脉微欲绝、盗汗不止？
│   ├── 是 → 炮附子（敛汗固表）
│   └── 否 → 生附子（强心起阳）
│
├── 冷到肘膝 + 下利清谷 + 脉微欲绝？
│   └── 是 → 四逆汤（生附子+干姜+炙甘草）★★★
│
└── 脑瘤或水肿难消？
    └── 是 → 生硫磺（升达头部、气化水湿）

症状：盗汗
├── 表阳虚 → 桂枝加龙骨牡蛎汤 + 炮附子
└── 亡阳 → 四逆汤辈

症状：心阳不足（心悸、胸闷、失眠）
└── 炙甘草汤（重用炙甘草 + 阿胶 + 生姜 + 大枣 + 桂枝 + 麻子仁 + 熟地 + 党参）
```

#### 倪师金句

> "阳气从 100 流失到 50，炮附子保住 50；阳气从 50 回到 100，那是生附子/生硫磺的事。"

> "生附子 2 钱起，有生附子症状的血癌才能降白血球；倪师最高用到 7 钱。"

> "不敢用炮附子就无法治病。"

#### 三个完整案例

**案例 1：血癌 WB 39→28（炙甘草汤证）**
- 辨证：脉结代（跳三四下停一下）+ 盗汗 24 小时不止 + 贫血
- 处方：炙甘草 10g + 生姜 + 大枣 + 桂枝 + 麻子仁 + 熟地 + 党参 + 阿胶 + 当归 + 白术 + 茯苓 + **炮附子 4g** + 龙骨 + 牡蛎
- 关键：炮附子治盗汗，不治手脚冰冷

**案例 2：血癌 寒热并结（生附子证）**
- 辨证：舌苔黄干 + 脉大 + 脚冰冷 + 失眠
- 处方：**生附子 2g** + 干姜 + 炙甘草 + 桂枝 + 白芍 + 大黄 + 黄芩 + 黄柏 + 黄连 + 防己 + 瓦楞子 + 牡蛎 + 紫根 + 茯苓 + 阿胶
- 关键：生附子 2 钱起，有生附子症状的血癌才能降白血球

**案例 3：脑瘤（生硫磺证）**
- 辨证：脑瘤需要阳气达头部
- 处方：**生硫磺**（性轻飘，可升达头部）
- 关键：生附子无法达脑，必须用生硫磺

#### 重要警告

> ⚠️ **生附子、生硫磺是剧毒药**，必须由执业中医师面诊开方、配伍、煎煮法、剂量。
> 
> ⚠️ **不可自行尝试**。即使是"小量"也可能在某些人身上引起严重毒性反应。
>
> ⚠️ 倪师虽然经验用到 7 钱，但这是在**严格辨证 + 配伍 + 久煎**的前提下。

### 九、药物选用总诀

倪师在讲药物选用时的核心原则：

1. **辨证为王**："对证就是补药"
2. **以意来得**："用悟的方式去了解，而不用去记它的名称"
3. **看质地**："看到药的颜色、形状、质地、味道，就能判断它的归经和功能"
4. **考虑炮制**：炮制改变药性（如石膏生用清热、煅用收湿）
5. **注意配伍**：单味药与复方完全不同
6. **安全第一**：附子、生硫磺、生半夏、商陆等高风险药**必须面诊**

## 第三部分：常用药物速查（按功效分类）

> 仅作学习参考，**不**给出剂量。

### 解表药
- **辛温解表**：麻黄、桂枝、生姜、葱白、羌活、独活
- **辛凉解表**：薄荷、蝉蜕、桑叶、菊花、葛根、升麻、柴胡

### 清热药
- **清热泻火**：石膏、知母、栀子、芦根
- **清热燥湿**：黄芩、黄连、黄柏、龙胆草、苦参
- **清热解毒**：金银花、连翘、板蓝根、蒲公英、紫花地丁
- **清热凉血**：生地、丹皮、玄参、紫草

### 泻下药
- **攻下**：大黄、芒硝、番泻叶
- **润下**：麻子仁、杏仁、桃仁
- **峻下逐水**：甘遂、大戟、芫花

### 祛风湿药
- **独活、羌活、防风、防己、秦艽、桑寄生**

### 利水渗湿药
