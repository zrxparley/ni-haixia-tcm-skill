## 一、十二经纳天干地支歌（基础）

### 1.1 天干歌

```
甲胆乙肝丙小肠，
丁心戊胃己脾乡，
庚属大肠辛属肺，
壬属膀胱癸肾藏，
三焦亦向壬中寄，
包络同归入癸水。
```

### 1.2 地支歌

```
肺寅大卯胃辰宫，
脾巳心午小未中，
申胱酉肾心包戌，
亥焦子胆丑肝通。
```

### 1.3 倪师解读

> "天干地支是中医五行的基础。甲乙是木，丙丁是火，脾胃是土，庚辛属金。五行都有阴阳，阴木就是肝，阳木就是胆，阴火就是心，阳火就是小肠。"

## 二、井荣俞经合（五俞穴）

### 2.1 阴经的五行排行

**阴经：木火土金水**

| 穴位 | 五行 |
|---|---|
| 井穴 | 木 |
| 荣穴 | 火 |
| 俞穴 | 土 |
| 经穴 | 金 |
| 合穴 | 水 |

### 2.2 阳经的五行排行

**阳经：金水木火土**（比阴经多一个原穴）

| 穴位 | 五行 |
|---|---|
| 井穴 | 金 |
| 荣穴 | 水 |
| 俞穴 | 木 |
| 经穴 | 火 |
| 合穴 | 土 |
| **原穴** | （阳经特有）|

### 2.3 五俞穴应用原则

| 病在 | 取穴 | 原理 |
|---|---|---|
| **脏** | 井穴 | 病在越深的地方，在指头末梢下针。井主心下满 |
| **色** | 荣穴 | 病变于色（青赤黄白黑）|
| **时间** | 俞穴 | 按时辰发病的取俞穴 |
| **音** | 经穴 | 声音变化取经穴 |
| **饮食** | 合穴 | 饮食问题取合穴 |
| **五脏不平衡** | 原穴 | 调整整体平衡 |

**倪师临床金句**：
> "动脉血管堵塞针井穴，痛马上去掉。"

## 三、五脏逼毒法

> 倪师独创。每个脏腑都有对应的逼毒发声法。

| 脏腑 | 发声 |
|---|---|
| 肺 | "呬"（xì）|
| 心 | "呵"（hē）|
| 肝 | "嘘"（xū）|
| 脾 | "呼"（hū）|
| 肾 | "吹"（chuī）|
| 三焦 | "嘻"（xī）|

**操作**：发声时配合动作，把对应脏腑的"毒"逼出。

## 九、公孙内关胃心胸（八脉交会穴）

> **公孙配内关，治所有胃、心、胸部的病。**

**公孙穴**：冲脉

**内关穴**：阴维脉
- 位置：腕横纹上 2 寸，掌长肌腱与桡侧腕屈肌腱之间
- 主治：阴维脉病、心胸胃病

## 十、针灸治症精选

### 1. 失眠

> "失眠治成能睡，睡得很好，本来全身黄疸也退了，小便排出来了，水肿没了。一个人能吃能喝能拉能睡，没有病。"

**健康标准**：能吃、能喝、能拉、能睡。

**治法**：根据失眠类型选穴
- 心肾不交 → 神门、内关
- 肝郁化火 → 太冲、行间
- 心脾两虚 → 心俞、脾俞

### 2. 中风

**风市穴**（大腿外侧，膝上七寸）→ 治中风、瘫痪的大穴

**急救穴位**（详见 `bimen-hantang.md`）：
- 百会放血
- 人中
- 十宣放血
- 涌泉
- 左额角烧发灰吹耳

### 3. 心脏病

- 心脏肥大 → 针灸配合中药
- 胸痛心律不整 → 内关、神门、心俞

### 4. 癌症辅助

- 乳癌 → 膺窗、乳根、膻中
- 肺癌 → 肺俞、中府、孔最
- 肝癌 → 期门、肝俞、太冲

### 5. 中风先兆

> **倪师特别强调**：
> 1. 失眠持续半年以上 → 立即针神门、内关
> 2. 手指麻 → 立即针灸（防 2-3 个月内中风）
> 3. 足胫骨麻 → 立即面诊（防 2 周内中风）

## 十一、学习路径

1. **先学天干地支歌**（必背）
2. **再学井荣俞经合**
3. **再学十二经原穴**（每经 1 个）
4. **再学任督二脉要穴**
5. **再学特定穴**（募穴、郄穴、络穴等）
6. **配合 `bimen-hantang.md`**：看中风急救穴位
7. **配合 `cases-classified.md`**：看倪师实际针药并用案例
