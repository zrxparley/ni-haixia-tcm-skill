## 核心篇目详解

### 篇 1：藏府经络先后病脉证（总纲）

**核心条文**：
- "上工治未病" — 倪师最常引用
- "见肝之病，知肝传脾，当先实脾" — 治未病思想
- "夫人禀五常，因风气而生长" — 人与自然

**倪师解读**：
- 上工治未病：不是治已病，是治未病
- 见到肝病，先实脾（木克土，预防脾病）
- 中医是治"未病"的医学

### 篇 2：痉湿暍病脉证治

**三种病**：
- **痉病**：项背强直、口噤、角弓反张
- **湿病**：身重、关节痛
- **暍病**：夏季中暑发热

**核心方剂**：
- **瓜蒌桂枝汤** → 柔痉（有汗）
- **葛根汤** → 刚痉（无汗）
- **麻黄加术汤** → 湿家身烦痛
- **麻黄杏仁薏苡甘草汤** → 风湿身重

**倪师特别强调**：
> "湿家身烦痛，可与麻黄加术汤，发其汗为宜；慎不可以火攻之。"
> 湿病不能火攻（火攻会加重）。

### 篇 3：百合狐惑阴阳毒证治

**三种病**：
- **百合病**：精神恍惚、饮食行为失调
- **狐惑病**：咽喉、前后阴溃疡（类似白塞病）
- **阴阳毒**：面部发斑、咽喉痛

**核心方剂**：
- **百合地黄汤** → 百合病
- **甘草泻心汤** → 狐惑病
- **升麻鳖甲汤** → 阳毒
- **升麻鳖甲汤去雄黄蜀椒** → 阴毒

**倪师特别强调**：
- 阴阳毒不是普通皮肤病，是重证
- 狐惑病是免疫病，倪师用甘草泻心汤治

### 篇 5：中风历节病脉证并

**中风先兆三联征**（**倪师特别强调**）：
1. 失眠持续半年以上
2. 手指麻（2-3 个月内中风）
3. 足胫骨麻（2 周内中风）

**任一出现，立即干预！**

**核心方剂**：
- **侯氏黑散** → 中风预防
- **风引汤** → 中风清热
- **防己地黄汤** → 中风血虚
- **头风摩散** → 偏头痛
- **桂枝芍药知母汤** → 历节
- **乌头汤** → 寒湿历节

**倪师中风急救**（详见 `bimen-hantang.md`）：
- 百会放血、人中、十宣放血、涌泉

### 篇 6：血痹虚劳病脉证并

**两种病**：
- **血痹**：气血不足、肌肤麻木
- **虚劳**：五劳七伤

**核心方剂**：
- **黄芪桂枝五物汤** → 血痹
- **薯蓣丸** → 虚劳（倪师治癌症用）
- **酸枣仁汤** → 虚劳虚烦不得眠
- **大黄䗪虫丸** → 干血痨（倪师治血癌参考）
- **肾气丸** → 虚劳腰痛

**倪师特别强调**：
> "治痿独取阳明" — 治痿证（重症肌无力等）必须从阳明经入手
> 薯蓣丸是治虚劳第一方，也是治癌症的辅助方

### 篇 8：奔豚气病脉证治

**奔豚**：自觉有气从少腹上冲胸咽

**核心方剂**：
- **奔豚汤** → 肝气奔豚
- **桂枝加桂汤** → 误汗奔豚
- **茯苓桂枝甘草大枣汤** → 水饮奔豚

**倪师"惊发"四部病**：
1. **惊** → 奔豚（气上冲）
2. **恐** → 欲作奔豚（脐下悸）
3. **忧** → 梅核气
4. **思** → 失眠

### 篇 9：胸痹心痛短气病

**核心方剂**：
- **瓜蒌薤白白酒汤** → 胸痹
- **瓜蒌薤白半夏汤** → 痰浊壅盛
- **枳实薤白桂枝汤** → 胸痹痞满
- **人参汤** → 虚寒胸痹
- **乌头赤石脂丸** → 心痛澈背

**倪师金句**：
> "心痛澈背，心背彻痛" → 心肌梗塞的可能

### 篇 11：五藏风寒积聚病

**核心方剂**：
- **旋覆花汤** → 肝着（肝气血郁）
- **麻子仁丸** → 脾约（大便硬、小便数）
- **甘草干姜汤** → 肺中冷

**脾约证**（倪师特别强调）：
- 胃强脾弱
- 大便硬如羊屎
- 小便数
- 治疗用麻子仁丸润肠

### 篇 12：痰饮咳嗽病脉证并

**四饮分类**：
- **痰饮**（肠胃）→ 苓桂术甘汤
- **悬饮**（胸胁）→ 十枣汤
- **溢饮**（肌肤）→ 大青龙汤
- **支饮**（胸肺）→ 葶苈大枣泻肺汤

**核心方剂**：
- **苓桂术甘汤** → 痰饮主方
- **十枣汤** → 悬饮（不可久服）
- **大青龙汤** → 溢饮
- **小青龙汤** → 支饮
- **木防己汤** → 支饮痞坚
- **泽泻汤** → 支饮冒眩

### 篇 13：消渴小便利淋病

**消渴 = 糖尿病**（倪师观点）

**三种消渴**：
- 上消：口渴多饮（白虎加人参汤）
- 中消：多食易饥（调胃承气汤）
- 下消：多尿（肾气丸）

**核心方剂**：
- **肾气丸** → 下消
- **白虎加人参汤** → 上消
- **五苓散** → 水逆
- **猪苓汤** → 阴虚淋

### 篇 15：黄瘅病脉证并治

**黄疸分类**：
- **谷疸** → 茵陈蒿汤
- **酒疸** → 栀子大黄汤
- **女劳疸** → 硝石矾石散
- **虚黄** → 小建中汤

**核心方剂**：
- **茵陈蒿汤** → 湿热黄疸
- **栀子大黄汤** → 酒疸
- **茵陈五苓散** → 黄疸轻证

### 篇 20-22：妇人病三篇

**妇人病总览**：
- **妊娠病**（篇 20）→ 桂枝茯苓丸、胶艾汤、当归散、白术散
- **产后病**（篇 21）→ 生化汤、当归生姜羊肉汤、竹叶汤
- **妇人杂病**（篇 22）→ 温经汤、土瓜根散、旋覆花汤

**倪师特别强调**：
- **生化汤** → 产后第一方
- **温经汤** → 更年期综合征第一方
- **桂枝茯苓丸** → 子宫肌瘤第一方
- **当归芍药散** → 妊娠腹痛

## 跨课程关联

### 与《伤寒论》的关系

> "金匮是延续伤寒论而来的，属于杂病范畴之内。"

**对比**：
| 维度 | 伤寒论 | 金匮要略 |
|---|---|---|
| 范畴 | 外感为主 | 杂病为主 |
| 重点 | 六经辨证 | 病种分类 |
| 治疗 | 经方 | 经方+杂方 |
| 学习顺序 | 先学 | 后学 |

### 与《神农本草经》的关系

- 金匮方剂使用的药都来自本经
- 倪师讲金匮时常引用本经药性
- 详见 `bencao-345.md`

### 与《黄帝内经》的关系

- 金匮的病机理论来自内经
- 倪师讲金匮时常引用内经条文
- 详见 `huangdi-neijing.md`

### 与《针灸大成》的关系

- 金匮病证常配合针灸治疗
- 倪师讲金匮时会涉及穴位
- 详见 `zhenjiu.md`
