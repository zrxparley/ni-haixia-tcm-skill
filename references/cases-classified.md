# 按疾病分类医案（V3.0 新增）

> 本文件整理 245 个倪师真实临床医案，按**疾病分类**索引。
>
> **数据来源**：[jangviktor-web/nihaixia](https://github.com/jangviktor-web/nihaixia) `cases/` 目录（6 个分类文件）。
>
> **数据时间范围**：2005-03-24 至 2008-08-11
>
> **使用方式**：
> 1. 按目录找疾病 → 看该病有哪些典型医案
> 2. 看医案号 → 在 `distilled_cases.md`（外部 jangviktor 仓 `distilled_cases.md`）中找完整摘要
> 3. 看完整原文 → 在外部 jangviktor 仓 `modules/03_yian.md` 中找
> 4. 用本仓库 `scripts/case-search.py` 做关键词检索
>
> **医疗边界**：本文件仅供倪海厦课程学习，**不构成医疗建议**。

## 七、医案使用指南

### 7.1 如何引用医案

在诊断模式或学习模式中提到相关病证时，引用医案格式：

```markdown
📚 倪师医案参考：[医案编号] — [疾病]
  - 日期：YYYY-MM-DD
  - 六经：[六经定位]
  - 方剂：[使用方剂]
  - 要点：[倪师治疗关键思路]
  - 完整原文：外部 jangviktor 仓 cases/[分类].md
```

### 7.2 医案学习法（倪师风格）

> 倪师原话：「看医案要像看侦探小说一样，先看症状，自己先辨证，再看倪师怎么辨，哪里不一样，为什么。」

**步骤**：
1. 遮住「六经」「方剂」字段
2. 只读「摘要」，自己先辨证
3. 再看「六经」「方剂」，对比自己的判断
4. 读摘要全文，理解倪师推理链条
5. 记录到错题本（`~/.workbuddy/memory/ni-haixia-errors.json`）
6. 进一步查 `bimen-hantang.md` 看闭门课相关专题
7. 套用 `case-replay.md` 模板做完整复盘

### 7.3 跨仓检索方式

| 需求 | 检索方式 |
|---|---|
| 按疾病找医案 | 本文件（按疾病分类索引）|

| 按关键词找医案 | 用本仓库 `scripts/case-search.py "关键词"` |
