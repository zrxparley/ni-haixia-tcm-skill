# 方剂解析模板（V3.0 新增）

> 用于按倪海厦方法**深度解析**单个方剂。
>
> **核心理念**：
> - 方剂 = 经方+ 加减
> - 倪师要求"张仲景怎么写你就怎么用"
> - 重点关注"为什么这样组合"
>
> **配合使用**：
> - `formula-patterns.md`（方剂方证速查）
> - `drug-properties.md`（药性总义）
> - `tcm-diagnosis.md`（六经辨证）
> - `cases-classified.md`（医案）
> - `honesty-boundary.md`（**必读**）

---

## 模板 1：标准方剂解析（10 步）

### 步骤 1：方剂基本信息

```markdown
📋 方剂基本信息

- **方名**：[桂枝汤]
- **来源**：[《伤寒论》]
- **类别**：[太阳病方]
- **所属六经**：[太阳]
- **倪师定位**：[太阳中风主方]
- **数据来源**：[formula-patterns.md / shanghan-lun.md / 课程出处]
```

### 步骤 2：组成与剂量

```markdown
💊 组成与剂量

| 药名 | 倪师剂量 | 汉代剂量 | 倪师特别强调 |
|---|---|---|---|
| 桂枝 | 9-15g | 三两 | 解肌 |
| 芍药 | 9-15g | 三两 | 收敛 |
| 甘草 | 6-9g | 二两 | 调和 |
| 生姜 | 3-5 片 | 三两 | 散寒 |
| 大枣 | 6-12 枚 | 十二枚 | 补中 |

⚠️ **重要**：以上剂量仅作学习参考，**不可**作为个人用药建议。
```

```markdown

- [太阳中风，营卫不和]

**倪师配伍解读**：
- [桂枝 + 芍药]：一散一收，调和营卫
- [甘草 + 生姜 + 大枣]：顾护脾胃，助汗源
- [桂枝 + 甘草]：辛甘化阳
- [芍药 + 甘草]：酸甘化阴

倪师金句：
- [ ]
```

### 步骤 4：核心方证

```markdown

**关键分水岭**：
- [有汗/无汗 → 桂枝汤/麻黄汤]
- [脉浮缓/脉浮紧 → 桂枝汤/麻黄汤]

**倪师辨证要点**：
- [ ] 发热
```

### 步骤 7：加减化裁

```markdown
🔄 加减化裁（倪师常用）

**桂枝加葛根汤**：
- 加葛根（治项背强）

**桂枝加附子汤**：
- 加炮附子（治汗漏不止、阳虚）

**桂枝去芍药汤**：
- 去芍药（治胸满）

**桂枝麻黄各半汤**：
- 桂枝 + 麻黄（治往来寒热但无恶心）

**桂枝二麻黄一汤**：
- 桂枝倍用、麻黄减半（治形如疟、日再发）

**小建中汤**：
- 加饴糖（治虚劳）
```

## 模板 2：方剂组对比（4 联方对比）

> 适合解析**功能相近的 4 个方剂**

```markdown
🔍 方剂组对比：[桂枝汤 / 麻黄汤 / 葛根汤 / 大青龙汤]

**共同点**：
- [都是太阳病方]
- [都治表证]

**辨证要点**：
| 方名 | 主症 | 关键鉴别 |
|---|---|---|
| 桂枝汤 | 有汗、恶风、脉缓 | 解肌调营卫 |
| 麻黄汤 | 无汗、恶寒、脉紧 | 发汗宣肺 |
| 葛根汤 | 项背强几几、无汗 | 葛根上行 |
| 大青龙汤 | 无汗、烦躁、脉紧 | 表寒里热 |

**倪师金句**：
- [有汗用桂枝，无汗用麻黄]
- [烦躁是大青龙的关键]

**使用流程**：
```
病人表证
    ↓
有汗/无汗？
    ↓
有汗 → 桂枝汤
    ↓
无汗 → 麻黄汤
    ↓
无汗 + 烦躁 → 大青龙汤
    ↓
无汗 + 项背强 → 葛根汤
```
```

## 模板 3：附子类方剂对比（**重点**）

> 倪师附子三品是核心临床创新，必须严格区分

```markdown
🔍 附子类方剂对比：[四逆汤 / 桂枝加附子汤 / 真武汤 / 附子泻心汤]

**附子三品**：
| 药物 | 靶器官 | 功能 |
|---|---|---|
| 生附子 | 心脏 | 强心阳、起阳 |
| 炮附子 | 肾脏/表 | 固肾阳、敛表阳 |
| 生硫磺 | 命门 | 强命门火、气化水湿 |

**方剂对比**：
| 方名 | 用何附子 | 病机 | 主症 |
|---|---|---|---|
| 四逆汤 | 生附子 | 心肾阳虚 | 四肢厥冷、脉微 |
| 桂枝加附子汤 | 炮附子 | 表阳虚 | 汗漏不止 |
| 真武汤 | 炮附子 | 肾阳虚水泛 | 水肿、肢冷 |
| 附子泻心汤 | 炮附子 | 痞证兼阳虚 | 心下痞、恶寒 |

⚠️ **高风险方剂**：
```

## 使用方法

1. **选方剂** → 从 `formula-patterns.md` 中选一个感兴趣的
2. **填模板** → 按上述步骤填写
3. **背诵方歌** → 倪师要求背诵
4. **复盘医案** → 找 3-5 个使用该方的医案
5. **配套学习** → 配合 `tcm-diagnosis.md` 的六经章节
6. **记录到错题本** → `~/.workbuddy/memory/ni-haixia-errors.json`
