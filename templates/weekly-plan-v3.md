# 周学习计划 V3 模板（V3.0 新增）

> 用于按倪海厦体系**生成每周学习计划**。
>
> **核心思想**：
> - 5 阶段学习路径（针灸→内经→本草→伤寒→金匮）
> - 零基础 12 个月
> - 每阶段有验收测试
> - 错题本 + 复习机制
>
> **配合使用**：
> - `learner-entry.md`（学习入口）
> - `lesson-map.md`（15 课学习地图）
> - `weekly-plan-v3.md`（本文件）
> - 状态文件 `~/.workbuddy/memory/ni-haixia-state.json`

---

## 5 阶段学习路径总览

| 阶段 | 时长 | 课程 | 目标 |
|---|---|---|---|
| 1 | 1-2 个月 | 针灸大成 | 掌握经络穴位 |
| 2 | 3-4 个月 | 黄帝内经 | 建立阴阳思维 |
| 3 | 5-6 个月 | 神农本草经 | 掌握 60 味核心药 |
| 4 | 7-9 个月 | 伤寒论 | 掌握六经辨证 |
| 5 | 10-12 个月 | 金匮要略 | 杂病辨治 |

## 自动升级触发条件

当用户说以下话时，触发相应动作：

| 触发词 | 动作 |
|---|---|
| "开始学习" | 生成第 1 周计划 |
| "今天学什么" | 根据 current_week 生成本周计划 |
| "升级计划" | 重评学习进度，输出优化方案 |
| "更新知识" | 检查知识库，补充新内容 |
| "学完了第 X 周" | 触发阶段测试，5 题简答 |
| "复习错题" | 按 review_date 拉取到期错题 |
| "重置学习" | 重置 current_week=1（需用户确认）|

## 错题本机制

**文件路径**：`~/.workbuddy/memory/ni-haixia-errors.json`

**记录格式**：
```json
[
  {
    "date": "2026-05-30",
    "week": 3,
    "question": "桂枝汤的配伍意义",
    "user_answer": "...",
    "correct_answer": "...",
    "review_date": "2026-06-06"
  }
]
```

**复习机制**：
- 错题记录 1 周后自动加入复习
- 复习题答对 3 次后从错题本移除
- 错题积累 50 条后必须完成复习

## 状态文件

**文件路径**：`~/.workbuddy/memory/ni-haixia-state.json`

**格式**：
```json
{
  "mode": "study",
  "current_week": 1,
  "current_stage": "针灸大成",
  "completed_weeks": [1],
  "last_active": "2026-05-30",
  "total_study_days": 0
}
```

**读写规则**：
- 每次对话开始时读取 state 文件
- 模式切换或学习进度更新时立即写回
- 文件不存在时自动创建

## 学习方法论（倪师建议）

1. **经典原文背诵** — 不只是看，要背
2. **六经辨证入门** — 抓住核心
3. **四诊训练** — 望闻问切都要练
4. **纠错式教学** — 错题要纠
5. **师徒问答** — 多问问题

**倪师金句**：
> "不懂伤寒，不算入门。"
> "你踩在巨人的肩膀上，不要怕学不会，轮子拿来就能用而不是让你发明轮子。"
