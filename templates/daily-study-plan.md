# 倪师中医学习计划模板（零基础12个月）

> 本模板由AI根据 `current_week` 自动填充，生成当周具体计划。

---

## 使用说明

- 每次对话开始时，读取 `~/.workbuddy/memory/ni-haixia-state.json` 获取 `current_week`
- 根据 `current_week` 判断所属阶段（1-4周=第一阶段，5-8周=第二阶段...）
- 自动生成当周计划，输出格式见下方

---

## 第X周学习计划（自动生成模板）

```
📅 【倪师中医学习计划 - 第X周】

🎯 本周目标：[根据current_week自动计算]
  阶段：[针灸大成/黄帝内经/神农本草经/伤寒论/金匮要略]
  本周里程碑：[具体可验收的目标]

📚 学习内容：
  - 经典：《[对应经典名]》第[篇/集]篇/集
  - 视频：倪师《[课程名]》第[集数]集
  - 背诵：[具体条文/方歌/穴位]
  - 实践：方证练习[X]例 / 经络描图[X]次

⏰ 每日安排：
  - 早晨（30分钟）：经典诵读 [具体篇目]
  - 午后（60分钟）：视频学习 [具体集数]
  - 晚间（30分钟）：笔记整理 + 今日复盘

📝 本周作业：
  1. [背诵任务]
  2. [理解任务]
  3. [实践任务]

✅ 完成标志（周末自测）：
  - [ ] 能背诵：[具体条文]
  - [ ] 能解释：[核心概念]
  - [ ] 能应用：[辨证/取穴/方药]

📌 倪师本周金句：
  "[根据week自动选取对应金句]"
```
